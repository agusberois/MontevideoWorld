# Montevideo World

MMORPG web isométrico (v1, prueba de concepto). Documentación completa en [`CLAUDE.md`](./CLAUDE.md).

```bash
npm install
cp apps/client/.env.local.example apps/client/.env.local   # opcional, el default ya apunta a localhost
npm run dev
```

Abrí http://localhost:3000 en dos pestañas, elegí un nombre en cada una, hacé clic en el piso para caminar y chateá.
